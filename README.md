# Qualidade-e-Teste-de-Software

Pesquisa

Quais as características de um Tester Ágil? Em quais momentos o Testes Ágil aparece no desenvolvimento de um software? (Detalhe)
R:
O Tester Ágil usa o mindset Ágil para tornar seu trabalho mais eficiente e entregar maior valor ao negócio. 
  O Tester tem como foco analisar o produto e criar um critério para garantir a qualidade do produto.
  O Tester Ágil se encontra em todas as partes do processo de desenvolvimento, recebendo e compartilhando 
  informações para procurar e prever bugs, para planejar, implementar e executar testes.

Quando um code review sentido e quando ele deixa de fazer sentido(No mínimo 3 motivos) ? De sua opinião sobre.
R: 
O code review é muito util para a prevenção e correção de bugs, seu intuito é deixar a equipe mais alerta.
  Entre outros benefícios temos também:
  ° Aprimoramento técnico;
  ° Maior nível de cooperação;
  ° Criação de soluções alternativas para os problemas;
Esta é uma prática util, porém não é um protocolo de segurança que ira impedir erros,  
mesmo sendo, aplicado por desenvolvedores experientes ainda podera haver erros, sendo eles:
  ° Falsa sensação de segurança;
  ° Melhorias ainda podem passar desapercebidas;
  ° Bugs podem não ser detectados;
Code review é útil porém, ainda deve ser aplicado com outros métodos de segurança.
